## Critical Patterns

### API Error Handling - ALWAYS USE `useApiToast` Hook

**IMPORTANT**: Never manually extract error messages from API responses. Always use the `useApiToast` hook.

```typescript
import { useApiToast } from "./hooks/useApiToast";

function MyComponent() {
  const { handleApiCall } = useApiToast();

  const handleSubmit = async () => {
    await handleApiCall({
      apiCall: () => api.postV1Resource(data),
      successMessage: "Resource created successfully",
      onSuccess: (response) => {
        // Handle success
      },
      onError: () => {
        // Optional: Handle error (toast is shown automatically)
      },
    });
  };
}
```

**What NOT to do** (deprecated pattern):

```typescript
// ❌ DON'T DO THIS
try {
  await api.postV1Resource(data);
  toast.success("Success");
} catch (error: any) {
  const errorMessage = error?.response?.data?.detail || "Failed";
  toast.error(errorMessage);
}
```

**Key features**:

- Automatically extracts `detail` from `ApplicationProblemDetailsModel`
- Shows success/error toasts consistently
- Returns result for custom handling: `const result = await handleApiCall(...)`
- Options: `showSuccessToast`, `showErrorToast` to control toast display

### Component Patterns

#### Form Pages (Create/Edit)

- Use `react-hook-form` with `zod` validation
- Use `useApiToast` for all API calls
- NO `formError` state or Alert banners for API errors
- Example: [src/components/pages/LocationFormPage.tsx](src/components/pages/LocationFormPage.tsx)

#### API Calls Pattern

```typescript
const [submitting, setSubmitting] = useState(false);
const { handleApiCall } = useApiToast();

const onSubmit = async (values: FormValues) => {
  setSubmitting(true);
  await handleApiCall({
    apiCall: () => api.postResource(values),
    successMessage: "Created successfully",
    onSuccess: () => navigate("/success"),
    onError: () => setSubmitting(false),
  });
};
```

### Data Tables with Pagination

**IMPORTANT**: Use TanStack Table with our standardized 3-file pattern for all paginated data tables.

**Structure**:

```
src/components/[feature]/
├── columns.tsx          # Column definitions (ColumnDef[])
├── data-table.tsx       # Reusable table component
└── [Feature]Page.tsx    # Page with data fetching
```

**Reference Implementation**: See `src/components/activities/` folder

**columns.tsx** - Define typed columns:

```typescript
import { ColumnDef } from "@tanstack/react-table";
import type { ActivityWithEmissionsResponse } from "@/generated/api";

export const columns: ColumnDef<ActivityWithEmissionsResponse>[] = [
  {
    accessorKey: "field_name",
    header: "Header",
    cell: ({ row }) => <CustomCell value={row.original.field_name} />,
  },
  // Actions column with meta callback:
  {
    id: "actions",
    cell: ({ row, table }) => {
      const onDelete = (table.options.meta as any)?.onDelete;
      return <Button onClick={() => onDelete(row.original.id)}>Delete</Button>;
    },
  },
];
```

**data-table.tsx** - Copy from `activities/data-table.tsx`:

- Accepts: `columns`, `data`, `pageNumber`, `pageSize`, `totalCount`, `onPageChange`
- Optional: `onRowClick`, `meta` (for passing callbacks to columns)
- Shows pagination controls and result counts

**Page Component** - Server-side pagination:

```typescript
const [data, setData] = useState<Item[]>([]);
const [pageNumber, setPageNumber] = useState(1);
const [pageSize] = useState(20);
const [totalCount, setTotalCount] = useState(0);

useEffect(() => {
  const fetchData = async () => {
    const api = getWitnesServerAPI();
    const response = await api.getV1Items({
      PageNumber: pageNumber,  // ⚠️ Capitalized (API param)
      PageSize: pageSize,
    });
    const pagedResult = response.data;
    setData(pagedResult.data ?? []);
    setTotalCount(pagedResult.total_count ?? 0);
  };
  fetchData();
}, [pageNumber, pageSize]);

return (
  <DataTable
    columns={columns}
    data={data}
    pageNumber={pageNumber}
    pageSize={pageSize}
    totalCount={totalCount}
    onPageChange={setPageNumber}
    onRowClick={(row) => navigate(`/items/${row.id}`)}
    meta={{ onDelete: handleDelete }}
  />
);
```

**Key Points**:

- Use **server-side pagination** (manualPagination in TanStack Table)
- API params: `PageNumber` and `PageSize` (capitalized from backend)
- Pass callbacks via `meta` prop to access in column definitions
- DataTable is reusable - copy from `activities/data-table.tsx` for new tables

## Common Pitfalls

1. **Don't manually extract API errors** - Use `useApiToast`
2. **Don't create formError state for API errors** - Hook handles this
3. **Don't show both Alert banner AND toast** - Just use toast
4. **Always call setSubmitting(false) in onError** - Prevents stuck buttons
5. **Don't edit src/generated/api.ts** - It's auto-generated
6. **NEVER add `handleApiCall` to useEffect dependencies** - Causes infinite loops! Only include actual dependencies like IDs
7. **Don't build tables from scratch** - Copy `activities/data-table.tsx` and create `columns.tsx`

## When Making Changes

1. **Adding new API calls**: Use `useApiToast` hook
2. **Creating forms**: Follow [LocationFormPage.tsx](src/components/pages/LocationFormPage.tsx) pattern
3. **Creating tables**: Copy `activities/data-table.tsx` and create `columns.tsx` following the 3-file pattern
4. **Adding new pages**: Create `.astro` file in `src/pages/`
5. **Type changes**: Run `npm run typecheck` before committing
6. **New patterns/conventions**: Update this file and `INSTRUCTIONS.md`
