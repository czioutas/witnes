PRD: Witnes — The CS "X-Ray" Diagnostic Tool1. The MissionTo eliminate the "Can you send a screenshot of your network tab?" conversation. Witnes provides a publicly accessible diagnostic link (witnes.io/{org}/{user}) that reconstructs a user's technical experience into a human-readable timeline.2. Data Acquisition Strategy (The "Aggressive" Gatherer)We don’t just track the page load; we track the heartbeat of the session.Standard Page Loads: DNS, TCP, SSL, and TTFB (Time to First Byte).SPA Transitions: Hooks into pushState. Measures the "Void" (the time between clicking a link and the first new pixel appearing).API Interception: Monkey-patch fetch and XMLHttpRequest.Goal: If a page is slow, we must be able to say: "It’s because /api/v1/orders took 4.2 seconds to respond."Environmental Context: * Network: Effective connection type (4G/5G/Wi-Fi), RTT, and downlink.Browser: Version, OS, and "Low Power Mode" detection.The "Final Package": Everything is bundled and shipped via navigator.sendBeacon during page transitions or tab closures.3. The Medallion Data PipelineIngress (Bronze): High-speed ingestion via Edge Workers into a Message Queue. No logic here, just capture.Processing (Silver): The pipeline parses the JSON. It maps API delays to specific backend endpoints. It tags sessions as "Product Issue" (Slow API/Server) vs. "User Issue" (Slow Wi-Fi/Old Browser).Dashboard Ready (Gold): Aggregated metrics for the 7-day retention window.4. The "CS View" (witnes.io/{org}/{user})This is a dedicated, shareable page that answers the question: "Why was it slow?"The Timeline View:A vertical scroll of the user's journey. Each entry (Page Load or SPA Nav) can be expanded to show:The Verdict: A bold badge: [NETWORK ISSUE], [BACKEND LAG], or [SMOOTH].The Network Waterfall: A simplified bar chart showing:Internet: (How long it took to reach your server).API: (Which specific request held up the page).Frontend: (How long the browser took to render the UI).The "Evidence" Box: Simple text for the CS to copy-paste to the user: "I noticed your connection latency was 500ms during your last checkout attempt. Are you on a VPN?"5. Storage & TiersCurrent Policy: "Store everything." 100% data retention for the first 7 days.Future-Proofing: Database schema includes retention_priority and tier_id to allow for 30, 60, or 365-day storage for premium tiers.6. Technical ConstraintsPrivacy: No PII (Personally Identifiable Information) in the logs by default. We only link to user-id provided by the host app.Performance: The script must be < 5KB gzipped and have zero impact on the host app's main thread.Refined Logic for "Product vs. User" Issue:If...Then Label As...TTFB or API Response > 1.5sProduct Issue (Backend)Network RTT > 300ms or 3G SpeedUser Issue (Connection)Total Time > 2s but API/Network are FastProduct Issue (Heavy Frontend)
